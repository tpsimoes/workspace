Customer Introduction

Bayer AG is an S500 strategic customer with Microsoft.
Bayer uses SAP as their primary ERP and data System.
Bayer landscape consists of 254 SAP systems which includes SAP System with HANA and Oracle Database respectively. All SAP systems using HANA DB are hosted in Azure, SAP systems using the Oracle databases are running in a private cloud hosted by CapGemini.
The SAP on Azure workload is divided in Cropscience, Pharma, and Consumer Health/Cross functional.

Customer Hot issues
Outdated Linux OS Versions

October 2024: Many of the customer's VMs are running outdated SUSE and RHEL Linux OS versions. The customer is currently negotiating the conditions for upgrade project with the Capgemini team. At the same time - primarily because of the expected long time to start and complete the upgrade - the customer is looking for information to purchase the extended support for both of these OS flavors. Microsoft organized multiple meetings with the customer and provided all the information needed in order to plan and execute the upgrade and also provided the information on how to purchase the extended support. The main focus of the customer was to investigate the supportability of the in-place upgrades, since in-place upgrades would make it possible to upgrade the OS versions without having to reinstall everything from the scratch and provision a full copy of the entire infrastructure during the upgrade process. However, some configuration scenarios do not fully support the in-place upgrade, such as upgrading the RHEL with Pacemaker from 7.x to 8.x. Also, it is unclear whether the SAP and other 3rd party software (antivirus...) fully support the in-place upgrade.
Because of those unknowns, it was decided to perform the PoC of the upgrade process in a test environment and evaluate all scenarios before implementing it in the production. The start of the PoC will depend on the contractual situation with the Capgemini.
